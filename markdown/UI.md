# User Interface

## Architecture

linkarchivetools is a backend library and command-line tool suite. It contains no web server, HTML templates, or graphical user interface components.

## Presentation Formats

### Terminal Text Summaries
- Generated by: dbanalyzer --summary, dbanalyzer --columns
- Format: plain text console output indicating table names, row tallies, and column lists

### Field-Specific Listings
- Generated by: dbanalyzer with attribute flags (--title, --description, --tags, --votes, --social)
- Format: formatted line output displaying requested record attributes per entry

### JSON Streams
- Generated by: dbanalyzer --json, db2json, db2feeds --output-format JSON
- Format: serialized JSON objects or arrays formatted for piping to CLI tools (such as jq) or ingestion by external services

### RSS Feeds
- Generated by: db2feeds, model/serializers.py
- Format: RSS 2.0 and Atom XML documents with channel headers, publication dates, and item metadata
